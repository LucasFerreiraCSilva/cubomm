# Exemplo: ocultar tempo até término da montagem

Abra `index.html` no navegador (duplo clique ou `Live Server`) e teste:

- Marque `Ocultar tempo até o término da montagem` para ocultar o contador durante a montagem.
- A preferência do usuário é salva no navegador e será restaurada automaticamente.
- Clique em `Iniciar montagem` para simular uma montagem de 10s.
- Ao terminar, o tempo final será exibido automaticamente.

Integre `index.html`, `app.js` e `styles.css` no seu projeto conforme necessário.
